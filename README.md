# Lampa Seasons Plugin

Плагин для медиацентра Lampa (lampa.mx), отображающий бейджи с информацией о вышедших сезонах и сериях на карточках сериалов.

## Установка в Lampa
1. Откройте **Lampa** -> **Настройки** -> **Расширения** (Плагины).
2. Нажмите **Добавить плагин**.
3. Вставьте ссылку:
   ```text
   https://side75.github.io/lampa-seasons-plugin/seasons.js
   ```
4. Перезагрузите Lampa.
